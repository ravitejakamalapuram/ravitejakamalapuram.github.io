Privacy Policy for JSON Workbench

Effective Date: September 21, 2026 | Publisher: Raviteja Kamalapuram
Summary: JSON Workbench is a local-first developer productivity tool. All JSON parsing, formatting, querying (via client-side WebAssembly), and schema validation execute strictly within your local browser. No document content or queries are ever sent to remote servers.

1. Single Purpose

JSON Workbench provides developers with a local-first workspace to inspect, format, transform (via JQ and DuckDB-Wasm), and validate JSON data entirely within the client browser context.

2. Data Collection and Usage

JSON Workbench maintains a strict zero remote data collection standard:

  • No JSON Data Transmission: Any JSON documents you paste, load, transform, or inspect remain solely in your browser memory. We never transmit your payloads to any external server or API.
  • No Personally Identifiable Information (PII): We do not collect, request, or store names, email addresses, or user identifiers.
  • No Browsing Activity Tracking: We do not observe or record web pages you visit, browsing history, or network requests.
  • No Third-Party Analytics: We do not integrate Google Analytics, telemetry libraries, advertising SDKs, or session-recording tools.

3. Permissions and Justifications

JSON Workbench requests only the following permissions:

  • storage: Used strictly to persist your editor settings (e.g. font size, indentation preferences, dark/light theme, and word wrap) locally across sessions via chrome.storage.local.

4. Data Storage and Retention

All editor preferences are retained in Chrome's sandboxed local storage on your machine. You can clear this data at any time by clearing extension data or uninstalling the extension.

5. Compliance with Chrome Web Store Policies

JSON Workbench adheres fully to the Chrome Web Store Developer Program Policies, specifically the User Data FAQ and Limited Use requirements. We affirm that:

  • User data is never sold to third parties.
  • User data is never used or transferred for purposes unrelated to the extension's single purpose.
  • User data is never used or transferred to determine creditworthiness or for lending purposes.
