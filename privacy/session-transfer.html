Privacy Policy for Session Transfer

Effective Date: September 21, 2026 | Publisher: Raviteja Kamalapuram
Summary: Session Transfer is a developer utility for transferring active web tab session state between browser profiles or devices. Session transfers execute point-to-point or via manual encrypted export/import. No session data is ever collected or logged by the developer.

1. Single Purpose

Session Transfer enables developers to export and import active browser tab session data (cookies and local storage keys for specific tabs) between browser environments.

2. Data Collection and Usage

  • No Server-Side Logging: Transferred session artifacts are generated directly in memory for export by the user.
  • Zero Third-Party Telemetry: No analytics or tracking libraries are included.
  • User-Initiated Actions: Operations only occur upon explicit user interaction with the extension popup.

3. Permissions and Justifications

  • cookies & storage: Required to read and write session cookies and storage items for user-selected transfer targets.
  • activeTab: Used to identify the current tab target for transfer upon toolbar icon click.
