Developer tools

Chrome extensions for frontend developers and QA engineers.

  • EchoKit: API Recorder & Mocker

    Record real API traffic once, then mock it reliably. No backend setup.

    LiveChromeFree + Pro
    • Captures fetch and XHR traffic and replays it as local mocks, from the popup or a DevTools panel.
    • Simulates latency, 4xx/5xx errors and blocked APIs; matches strictly, by wildcard, ignoring query strings, or by GraphQL operation.
    • Exports to HAR and Postman. Pro adds unlimited recordings and GitHub Gist team sync (Pro features are free for now).
    Add to Chrome echokit.dev
    Privacy policy GitHub repo

  • JSON Workbench

    Inspect, transform, validate, diff and query large JSON without it leaving your browser.

    LiveChrome
    • Opens large JSON, JSONL and NDJSON as a tree or table with no loss of numeric precision.
    • Builds repeatable transform pipelines with jq, JSONata and local DuckDB SQL.
    • Infers JSON Schema, diffs two payloads as an RFC 6902 JSON Patch, and exports JSON, CSV or TSV.
    Add to Chrome
    Privacy policy GitHub repo

  • CORS Enabler

    Relax CORS for local development in one click, using Chrome's own rule engine.

    Coming soonChrome
    • Adds CORS response headers with Manifest V3 declarativeNetRequest rules, without reading request bodies.
    • Custom headers and presets for the development backends you target.
    • A diagnostics view shows which rule matched which request.
    Follow on GitHub
    Privacy policy

  • Session Transfer

    Move a logged-in browser session to another Chrome profile or device, with no cloud involved.

    Coming soonChrome
    • Transfers cookies (including HttpOnly), localStorage, sessionStorage, IndexedDB and Cache Storage.
    • Packages are AES-256-GCM encrypted with a one-time code and expire after 5 minutes.
    • A package restores only into its own origin, and you choose to replace, merge or cancel.
    Follow on GitHub
    Privacy policy

Apps

Android apps on Google Play.

  • InvTrack

    Track what you invested and what came back, for assets that have no daily market price.

    LiveAndroid
    • Built for FDs, P2P lending, gold, chit funds and other alternative investments.
    • Calculates XIRR, MOIC and CAGR from your own cash-flow ledger.
    • Includes goal tracking and a FIRE number calculator with India-friendly defaults. Works offline.
    Get it on Google Play
    Privacy policy: in the app, under Settings, About GitHub repo

  • TelePort

    A web browser on your Android TV, controlled from your phone.

    LiveAndroid TVAndroid
    • Multi-tab browsing on the TV, with an air-mouse pointer driven by your phone's motion sensors.
    • Virtual touchpad, D-pad and keyboard input from the phone remote.
    • Built-in ad and popup blocker. Runs on your local Wi-Fi with no cloud or account.
    Get it on Google Play
    Privacy policy GitHub repo
